---

## 역할
개별 기사 요약을 모두 취합하여 하나의 종합 브리핑 보고서를 생성합니다.

## 입력

- outputs/article-*/summary.md: 각 기사의 개별 요약 파일

## 작업 지침

1. outputs/ 디렉토리에서 모든 `article-*/summary.md` 파일을 읽는다
2. 각 기사 요약을 번호 목록으로 정리한다
3. 전체 기사의 공통 주제나 핵심 트렌드를 한 문단으로 도출한다
4. 종합 브리핑 보고서를 `outputs/final-report.md`에 작성한다

보고서 형식:
```
# 종합 브리핑 보고서

## 개별 기사 요약
1. [기사 제목] - 요약 내용
2. [기사 제목] - 요약 내용
...

## 핵심 트렌드
(공통 주제 분석)
```

## 산출물

outputs/final-report.md
