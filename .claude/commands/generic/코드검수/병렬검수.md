---
description: 선택된 관점별 독립 서브에이전트를 병렬 실행하여 각각 review 리포트를 생성한다
---

## 역할
입력된 브랜치·커밋 해시를 기반으로 검토 대상 diff를 추출하고, 활성화된 각 리뷰 관점에 대해 독립적인 서브에이전트를 **동시에** 실행한다. 각 서브에이전트는 서로의 컨텍스트를 공유하지 않으며, 결과는 세션 폴더에 개별 파일로 저장된다.

## 입력
- `branch`: 검수 대상 브랜치명
- `commit_hashes`: 커밋 해시 목록 (비어 있으면 브랜치 전체 diff 사용)
- `review_simplify`, `review_clean_code`, `review_security`, `review_performance`, `review_type_safety`, `review_accessibility`: 각 관점 활성화 여부 (boolean)
- 세션 폴더 경로

## 작업 지침

### 1. 검토 대상 diff 추출
- `commit_hashes`가 제공된 경우: `git diff <first_hash>^..<last_hash>` 또는 개별 해시들의 diff를 합산
- `commit_hashes`가 비어 있는 경우: `git diff $(git merge-base main {branch}) {branch}` 로 브랜치 전체 diff 추출
- diff 결과와 변경된 파일 목록을 메모리에 보유한다

### 2. 활성화된 관점 목록 확인
입력값에서 `true`인 review_* 필드만 추려 실행할 관점 목록을 결정한다.

### 3. 관점별 서브에이전트 병렬 실행
Agent 도구를 사용해 활성화된 모든 관점의 서브에이전트를 **단일 메시지에서 동시에** 호출한다. 각 서브에이전트는 아래 지침에 따라 독립적으로 동작한다.

#### [Simplify] `review_simplify`가 true인 경우
- 변경된 파일들에 대해 `/simplify` 스킬을 실행한다
- 점검 기준: 불필요한 추상화 제거, 중복 로직 통합, 함수 단순화, 불필요한 상태 제거
- 산출물: `세션폴더/review-simplify.md`

#### [클린 코드] `review_clean_code`가 true인 경우
- Robert C. Martin *Clean Code* 원칙을 기준으로 점검한다
  - 네이밍: 의도를 드러내는 이름, 발음 가능한 이름, 검색 가능한 이름
  - 함수: 한 가지 일만 수행, 20줄 이하 권장, 부수 효과 없음
  - 주석: 코드로 표현 불가한 경우에만 작성
  - 중복: DRY 원칙 준수
  - 경계: 외부 API·라이브러리 래핑
- 산출물: `세션폴더/review-clean-code.md`

#### [보안] `review_security`가 true인 경우
- OWASP Top 10 (https://owasp.org/www-project-top-ten/) 기준으로 점검한다
  - XSS, SQL Injection, 인증·세션 취약점
  - 민감 데이터(API 키, 토큰, 개인정보) 하드코딩 여부
  - 입력값 검증 누락
  - 의존성 취약점
- 산출물: `세션폴더/review-security.md`

#### [성능] `review_performance`가 true인 경우
- 점검 기준:
  - React: 불필요한 리렌더링, useMemo/useCallback 누락 또는 과용, key prop 오용
  - 알고리즘: O(n²) 이상의 불필요한 중첩 루프, 반복 연산 캐싱 가능 여부
  - 번들: 불필요한 대용량 import, 코드 스플리팅 기회
  - 네트워크: 중복 요청, 워터폴 요청 패턴
- 산출물: `세션폴더/review-performance.md`

#### [타입 안전성] `review_type_safety`가 true인 경우
- 점검 기준:
  - `any` 타입 남용 (필요한 경우 `unknown` 사용 권장)
  - 타입 단언(`as`) 불필요 사용
  - 함수 반환 타입·파라미터 타입 누락
  - 런타임과 타입 정의 불일치
  - `strictNullChecks` 우회 패턴
- 산출물: `세션폴더/review-type-safety.md`

#### [접근성] `review_accessibility`가 true인 경우
- WCAG 2.1 AA 기준 (https://www.w3.org/TR/WCAG21/) 으로 점검한다
  - 이미지 alt 텍스트 누락
  - aria-label, aria-describedby 누락 또는 부정확
  - 키보드 포커스 순서·트랩 문제
  - 색상 대비 우려 (컴포넌트 구조 기준)
  - 시맨틱 HTML 미사용
- 산출물: `세션폴더/review-accessibility.md`

### 4. 완료 확인
모든 서브에이전트가 종료된 후, 세션 폴더에 각 리포트 파일이 생성되었는지 확인한다.

## 산출물

- `세션폴더/review-clean-code.md` (활성화된 경우)
- `세션폴더/review-security.md` (활성화된 경우)
- `세션폴더/review-performance.md` (활성화된 경우)
- `세션폴더/review-type-safety.md` (활성화된 경우)
- `세션폴더/review-accessibility.md` (활성화된 경우)

각 리포트 파일 구조:
```
# Review: {관점명}

## 요약
전체적인 평가 한 줄 요약

## 발견된 문제
### [심각도: 높음/중간/낮음] 문제 제목
- 위치: 파일명:라인번호
- 설명: 구체적인 문제 내용
- 권장 수정: 수정 방향 또는 예시 코드

## 통과 항목
문제가 없는 항목 간략 기술
```
