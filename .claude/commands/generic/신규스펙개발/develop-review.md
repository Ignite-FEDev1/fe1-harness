[읽어야 할 자료]

□ else / if else 사용이 없다 (early return, ternary, switch로 대체되어 있다)
□ 순수 HTML 태그 대신 공통 컴포넌트를 사용했다

□ export 패턴이 기존과 일치한다
□ 컴포넌트 props 타입 정의 방식이 기존과 일치한다
□ 불필요한 추상화/유틸/헬퍼가 없다
□ 기획서에 없는 기능이 추가되지 않았다
□ .cursor/rules/ 또는 CLAUDE.md에 명시된 규칙을 준수했다 (해당 파일이 있는 경우)

타입 안전성:
□ any 사용이 없다
□ 모든 변수/함수의 타입이 명확하게 정의되어 있다
□ BE 미확정 타입에 TODO 주석이 있다
□ mock 데이터가 실제 API 응답 구조와 동일한 타입이다
□ 기존 타입 확장 시 기존 패턴(union, intersection, generic)을 따른다
