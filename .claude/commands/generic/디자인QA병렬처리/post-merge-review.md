## 역할
이 에이전트는 최종 머지 브랜치를 대상으로 충돌이 올바르게 해결되었는지, 각 티켓의 변경사항이 모두 반영되었는지 검증하고 통합 검수 리포트를 작성한다.

## 입력
- 티켓 목록: {tickets}
- 베이스 브랜치명: {base_branch}
- 최종 머지 브랜치명: {merge_branch}
- 각 티켓별 검수 리포트: `review-{branch}.md` 파일들

## 작업 지침

### 1단계: 충돌 해결 검증
- `{merge_branch}` 브랜치의 코드에 충돌 마커(`<<<<<<<`, `=======`, `>>>>>>>`)가 남아있지 않은지 확인한다.
- 충돌 해결 과정에서 코드가 깨지거나 의도치 않게 삭제된 부분이 없는지 확인한다.

### 2단계: 티켓별 변경사항 반영 여부 검증
각 티켓 브랜치(`{tickets[*].branch}`)에 있던 변경사항이 `{merge_branch}` 에 모두 포함되어 있는지 확인한다.
- `git diff {base_branch}...{merge_branch}` 와 각 티켓 브랜치의 diff를 비교한다.
- 누락된 변경사항이 있으면 리포트에 명시한다.

### 3단계: 티켓별 검수 리포트 취합
각 `review-{branch}.md` 파일을 읽어 전체 검수 결과를 집계한다.

### 4단계: 통합 검수 리포트 작성
아래 경로에 통합 검수 리포트를 작성한다: `review-merged.md`

**리포트 포함 내용:**
- 머지 브랜치명 및 베이스 브랜치명
- 처리된 티켓 수 및 각 브랜치 목록
- 충돌 해결 검증 결과 (이상 없음 / 이슈 있음 + 상세 내용)
- 티켓별 변경사항 반영 여부 (전체 반영 / 누락 항목 목록)
- 티켓별 검수 결과 요약 (재수정 횟수, 최종 통과 여부)
- 종합 판정 (정상 완료 / 수동 확인 필요)

## 산출물
