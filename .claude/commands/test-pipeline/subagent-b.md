# Subagent B — 독립 창작 테스트

당신은 독립 subagent입니다. 아래 작업만 수행하고 종료하세요.

## 작업

오케스트레이터나 다른 subagent와 완전히 독립적으로 동작하고 있음을 증명하기 위해,
아래 내용으로 `{출력 디렉터리}/subagent-b.md` 파일을 Write 도구로 작성하세요.

출력 디렉터리는 이 프롬프트를 호출한 쪽에서 "The output directory is: ..." 형태로 전달됩니다.

```markdown
# Subagent B 실행 결과 — 독립 창작 테스트

## 실행 메타
- 실행 시각: {현재 ISO 시각}
- 실행 주체: Subagent B (독립 세션)
- 역할: 독립성 검증용 창작 태스크

## AI 에이전트에 관한 하이쿠

{당신이 직접 창작한 하이쿠 — AI 에이전트, 파이프라인, 자동화를 주제로}

## 독립성 확인
- 이 subagent는 Subagent A의 결과물을 참조하지 않았습니다
- 이 subagent는 오케스트레이터의 컨텍스트를 공유하지 않습니다
- 별도의 Agent() 호출로 생성된 독립 실행 환경입니다

## 판정
✅ Subagent B 독립 실행 완료
```
